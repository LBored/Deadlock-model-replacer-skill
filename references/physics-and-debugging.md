# 实时物理和故障排查

## 三类数据分别验证

1. 骨骼动画/蒙皮决定正常动作形状。
2. 布料/头发模拟产生相对身体的惯性，由引擎代理、控制点、约束和碰撞体驱动。
3. 死亡布娃娃靠刚体及其关节连接；碰撞形状存在不代表关节存在。

实时物理要求不能以纯骨骼跟随或 Blender 烘焙缓存交差。先验证一个小布片的实际加载与摆动；当前链路有游戏验证可直接复用。源代理和成品中的节点/约束都存在，只能说明数据已输出，不证明碰撞生效。

## 布料制作

裙子用低面、单层、连续代理，腰部固定、下摆动态；头发分束，根部固定、末端动态。渲染网格平滑映射到代理控制，避免跨不连续的参考坐标系插值。布料专用组/属性与普通皮肤权重分离保存。对代理自身重叠、初始身体穿插和重复连接先做检查。

身体碰撞体随骨盆、大腿、躯干、头颈、肩部骨骼运动；其坐标必须转换到被绑定骨的局部空间，核对半径、端点、碰撞层和实际编译字段。刚体碰撞和布料碰撞的配置可能不同，不能互相代替。

调节约束长度、回归目标、最大位移、弯曲、阻尼与惯性，控制变形而非用巨大碰撞体撑成另一件衣服。一次修改可归因的一组参数。引擎可能不提供地面或自碰撞，先验证能力再设计替代。

有限腿部支撑可缓解大幅抬腿穿模，但整片裙摆跟腿会产生裤腿式折叠。使用平滑分区的低幅支撑，检查前后左右与腰胯过渡，并保留代理骨骼。撤掉全部后裙腿权重可能使行走自然却让跳跃/滑铲严重穿插；两种都不是普遍正确方案。内部补片只在明确需要覆盖、且同动作不会裂开时采用，不能把增加遮挡面当成拓扑修复。不要未经用户接受就删掉腿部皮肤掩盖穿模。

头发“没有物理”应核查：根以外是否全部固定、渲染权重是否真正引用动态控制、代理是否导出、目标约束是否过强、运动参考是否合理。加入胸背碰撞/改变参考时同时检查弯腰、蹲下和复活。

## 截图到诊断

| 症状 | 先查证据 | 对应处理与复查 |
|---|---|---|
| 裙子某帧像缺了一块 | 源/导出三角面数量、边界；相同帧双面查看；权重连续性；碰撞折叠；Alpha | 真缺口修拓扑；翻面/折叠修权重和约束；遮罩错修材质。补面前先定因 |
| 后裙随腿踢动、形状分叉 | 前后分区权重、代理父骨与参考空间 | 降低局部直接跟随、连续映射，比较原始静态轮廓及动态防穿效果 |
| 单侧大腿/胯穿出 | 实际解剖左右、该区皮肤/裙子权重和碰撞间距 | 小范围校正同侧支撑和间距，复查横移/跳跃，不整体扩裙 |
| 眼睛/衣领黑块或消失 | 重复反面、叠面、材质 Alpha 输入及编译缓存 | 分离遮挡、缺图和 shader 原因，近景与 UI 姿势复查 |
| 拇指反折 | 根骨轴、掌心方向、近掌权重、目标真实动画 | 多姿势修绑定/表面，不只调一个静止截图 |
| 正常动画完好，死亡后散架 | 刚体名称、关节数组、索引和 bind frame | 恢复/重建正确连接，检查死亡→尸体停留→复活 |
| 技能手持道具消失 | 原身体网格面组、bodygroup/LOD、道具权重 | 将原道具网格独立保留；只有骨骼与挂点不能显示网格 |

## 死亡关节修复

读取当前原版和候选的物理结构，按刚体语义名称构图。若骨架和刚体局部绑定兼容，可恢复缺失的关节：按名称映射两个端点索引，保留局部框架、角度限制、阻尼和碰撞开关；检查关节锚点在绑定世界空间重合。若绑定不同，应重算框架/重新制作关节，不直接复制。

检查预期人体连通分量，允许原设计中独立的武器/附件存在；不要强行把所有刚体连成一棵树。修复后分别验证非关节物理、布料和碰撞保持，重复命名资源块按原序号保留。只在骨架、索引、节点和引用全部匹配时复用整个物理块。

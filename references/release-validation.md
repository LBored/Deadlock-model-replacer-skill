# 编译产物、范围控制和交付

## 隔离构建

stage 是本次包的完整明确资源集；不要把日志、原始贴图、旧导出、全部游戏材质打进去。自定义材质使用独立命名空间，覆盖路径保留游戏实际要求的相对路径。依赖在当前原游戏或此包中可解析，不复制未变化且游戏可提供的资源来凑齐目录。

记录源模型和基线哈希、工具版本、单位/导出配置、命令与返回码。构建函数遇到失败停止发布该候选；修复后复用未受影响的阶段。旧版独立保留。参数调整产生 A/B 时，先完成 A 的包及源归档再派生 B。

## 自带清单检查

`asset_audit.py` 仅需 Python 3.10+ 标准库，使用显式输出位置，不自动创建临时文件。输出放在被扫描目录之外。VPK 只读；支持 Valve v1/v2 的内置 payload、preload 和命名为 `_dir.vpk` 的分卷索引，未知容器拒绝而非猜测。

```text
python asset_audit.py snapshot --input accepted.vpk --output accepted.manifest.json
python asset_audit.py snapshot --input candidate.vpk --output candidate.manifest.json
python asset_audit.py compare --baseline accepted.manifest.json --candidate candidate.manifest.json --allow-add "sounds/vo/target/*" --output delta.json
```

此例允许新增指定语音路径，原有资源变化或删除仍会失败。模型修复用 `--allow-change` 加精确模型路径；删除必须显式用 `--allow-remove`。`*` 是 glob 通配符，包含 `/`，严格修改范围优先使用完整路径。允许列表是最大范围，不证明必须修改的文件已经修改；另核对实际预期新增集、数量及依赖。

退出码：0 表示扫描/允许范围检查通过；1 表示比较发现超范围变化；2 表示输入、解析、CRC 或其他执行错误。JSON 报告列出新增、删除、变化及未变数量。清单默认只记录输入文件或目录名；仅在本地确有诊断需要时使用 `--include-source-path` 写入绝对路径。公开分享前仍应检查报告内容，只分享所需文件。

## 检查层次

| 层次 | 必查内容 | 不能据此声称 |
|---|---|---|
| 源工程 | 骨架子集、绑定、权重、UV/材质、代理/碰撞、LOD | 导出结果必定一致 |
| 编译资源 | 同名骨父子/rest、有效影响、道具、动画图、挂点、材质和物理字段 | 游戏动作/物理必定正确 |
| 包文件 | 精确路径、CRC、包/块校验、依赖、基线逐文件哈希 | 用户实际启用了此包 |
| 独立解码 | 成品网格/贴图/声音与预期一致，所有 LOD/变体存在 | 中间格式可忠实复现全部 shader/物理 |
| 游戏 | 当前包哈希、场景、动作、状态切换、视觉与声音证据 | 未测试的动作或未来版本同样通过 |

审计比较不等于游戏验收。安装前检查已加载 Mod 中的同路径冲突；按当前游戏已验证的方法操作，选择未占用的文件名。不要继承案例机器上的安装文件名，也不要覆盖游戏原始主包。

## 聚焦复测

首版覆盖站立、奔跑/转身、左右横移、跳跃/空中冲刺、滑铲、射击、换弹、近战、各技能、受击、死亡与复活、UI 展示、远距离 LOD。后续回归覆盖本次改动及关联动作，复用已有通过证据。

实时物理检查独立惯性、急转、连续运动、连续死亡/复活后重置，不持续抖动、拉长或穿身；对不支持的碰撞类型明确说明。材质检查明暗环境、正侧背、脸/手近景和透明边缘。记录性能时使用相同场景、相同设置及基线包，注明测量方式。

截图/视频应附候选包名/哈希、复现动作和时刻。把局部修复的收益与回归一起记录，不用一项数字改善掩盖新问题。用户允许少量穿模时以其明确接受标准为准，不无休止重做已接受外观。

## 交付物

安装包、可编辑模型与材质/物理源、引擎工程、参数化构建脚本、依赖版本、资源清单、预览和测试记录。说明中写安装、冲突排查、停用/卸载、回滚及素材作者/来源。候选与已通过游戏验收版本明确标注；缺少实际游戏测试时只保留这项为待验证，不虚构结果，也不阻止已授权离线工作完成。
